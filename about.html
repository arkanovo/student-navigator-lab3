О ПРОЕКТЕ

Для тех, кто начинает

Цель сайта — помочь студенту выбрать следующий шаг: спланировать учебную задачу, найти документацию и попробовать знания на практике. Здесь нет регистрации, платных материалов и форм отправки персональных данных.

Как устроен сайт

Пять отдельных HTML-страниц связаны общим меню. Страницы используют единые стили и относительные ссылки, поэтому подходят для публикации в репозитории GitHub Pages.

Статистика посещений

Для учебного исследования подключён именной счётчик LiveInternet. Внешний счётчик получает технические сведения о посещении: адрес страницы, источник перехода и характеристики браузера. Расширения браузера могут блокировать счётчик.

Источники и материалы

Тексты рекомендаций составлены для этого проекта. Справочные ссылки ведут на MDN Web Docs, GitHub Docs и VS Code Docs.
