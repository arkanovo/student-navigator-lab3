# Студенческий навигатор

Пять статических HTML-страниц. Сборка и зависимости не нужны.

Сайт: https://arkanovo.github.io/student-navigator-lab3/

## Публикация
GitHub Pages: main, /(root). После push страницы обновляются автоматически.

## Статистика LiveInternet
На всех пяти страницах установлен официальный именной счётчик count1 (88×31, t52.6).
Кабинет: https://www.liveinternet.ru/stat/count1/
Код получен владельцем через форму регистрации именного счётчика.
На каждой странице один считающий запрос. Не добавляйте второй счётчик.
Именной счётчик установлен только на этом сайте: не ставьте count1 на другие лабораторные, иначе данные объединятся.
Для именных счётчиков недоступны некоторые отчёты, включая переходы на сайты и позиции в поисковых системах.

Собирайте статистику 7–14 дней и привлеките не менее 50 реальных пользователей.
Не складывайте суточных уникальных посетителей для получения уникальных за весь период.
Повторные обновления страницы одним человеком не заменяют реальную аудиторию.

## Локальный просмотр
python -m http.server 8765
Счётчик установлен непосредственно в HTML, поэтому для чистых данных проводите дальнейшие проверки до включения кода или отдельно помечайте свои тестовые посещения.

Материалы: https://www.liveinternet.ru/help/group.html
