# Студенческий навигатор

Пять статических страниц для лабораторной работы по LiveInternet.

## Публикация
Settings → Pages → Deploy from a branch → main → /(root) → Save.
Адрес после успешной публикации: https://arkanovo.github.io/student-navigator-lab3/

## LiveInternet
1. Зарегистрируйте полный адрес сайта на https://www.liveinternet.ru/add?lang=ru.
2. Выберите счётчик 88×31. Проверьте код, выданный сервисом, на https://www.liveinternet.ru/code?lang=ru.
3. При необходимости замените analytics.js официальным выданным кодом (один считающий запрос на страницу).
4. В analytics-config.js установите enabled: true после регистрации и проверки адреса site.
5. Откройте все пять страниц опубликованного сайта, затем проверьте поступление просмотров в кабинете.

Счётчик не активирован до регистрации. Заглушка в подвале не является работающим счётчиком.
Собирайте данные 7–14 дней, привлеките не менее 50 реальных пользователей. Не подменяйте пользователей перезагрузками страницы.

## Локальная проверка
Из этой папки: python -m http.server 8765. Откройте http://localhost:8765/.
Зависимостей и сборки нет. Все внутренние ссылки относительные.
